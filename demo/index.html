BirdID

Android bird identification by photo and sound — region-specific AI models, image+audio fusion, and a FastAPI/AWS backend.

Download Android APK (v1.9, 9.1 MB)

Android 6.0+ required. Internet connection required for identification.

This page demonstrates a real, functioning Android application as a portfolio case study. It is not affiliated with or endorsed by any freelance platform, and does not facilitate contact or business outside of it.

What this demonstrates

  • Computer vision / image classificationRegion-specific AI models (18 biomes) identify bird species from one or more photos, with seasonal-plumage awareness.
  • Audio classification & signal processingIdentifies birds from a recorded song or call using dedicated per-region audio models (7 biomes).
  • Multimodal fusionCombines photo and audio predictions of the same bird into a single, more confident result.
  • REST API & AWS backendFastAPI backend on AWS EC2, served over HTTPS (nginx + Let's Encrypt), with models hosted on S3.
  • Native in-app billingHuawei In-App Purchases (HMS IAP) integration for auto-renewable subscriptions, with server-side receipt verification against Huawei's API.
  • Native Android development beyond standard pluginsA custom Java plugin provides geolocation via the Android framework's LocationManager, for devices without Google Play Services.

How to test

  1. Download the Android APK using the button above.
  2. Open the downloaded file on your Android device (via your browser's downloads or a file manager).
  3. Android will ask for permission to install from this source — this is standard for any APK installed outside an app store. Allow it for this install only if you choose to proceed.
  4. Launch BirdID and create a free account (email address + a confirmation code sent by email — no payment required).
  5. Try the suggested demonstration below.

Minimum Android version: 6.0 (API 23). An internet connection is required — identification requests are processed by the backend API, not on the device. Camera and microphone access are requested only when you use those features.

Suggested demonstration

Take or choose a photo of a bird, submit it for identification, and review the predicted species, confidence score, and taxonomy (order, family, genus). Then record the bird's call (or play a recording near the microphone) and submit it as well — the app fuses both into one result and shows a reference recording of the species' real call.

Technical architecture

Android app (Capacitor + Ionic + React; native Java plugins for Huawei IAP and GMS-free geolocation)
→ HTTPS REST API (FastAPI)
→ AWS EC2 (Docker container, nginx reverse proxy, Let's Encrypt TLS)
→ ONNX Runtime inference — 18 region-specific image models + 7 audio models (hosted on S3)
→ SQLite (accounts, quota, subscriptions) + AWS SES (email verification codes)
→ Huawei IAP server-side receipt verification (subscriptions)
